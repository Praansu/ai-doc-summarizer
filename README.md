# AI Doc Summarizer

RAG-based PDF question answering system built with LangChain and Streamlit.

## Features
- Upload PDF documents and ask questions in natural language
- RAG pipeline with document chunking, vector embeddings, and semantic search
- Clean Streamlit UI for interactive document analysis
- Powered by OpenAI GPT-4o-mini

## How to Run
```
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- LangChain (RAG pipeline)
- ChromaDB (vector store)
- OpenAI Embeddings + GPT-4o-mini
- Streamlit (UI)
